# Stremio Extension

Starter Stremio addon project.

## Run locally

```bash
pnpm install
pnpm dev
```

The addon manifest will be available at:

```text
http://127.0.0.1:7000/manifest.json
```

Paste that URL into Stremio's addon search/install box while the server is running.

## Scripts

- `pnpm start` - run once
- `pnpm dev` - run with Node watch mode

## Next steps

We can now customise the manifest, catalog, metadata, and stream handlers for the actual addon idea.
